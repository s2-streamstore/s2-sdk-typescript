    Class S2NetworkPolicies

    Account-scoped helper for listing, creating, getting, and deleting network policies.

    A network policy restricts where an access token may be used from. Bind one when issuing a token with S2AccessTokens.issue.

    Acquire via S2.networkPolicies. Use S2NetworkPolicies.listAll for async iteration.
